# [I] 30단계 — 롱 전용 vs 롱+숏 (숏 제거 효과) 보고서

**날짜**: 2026-06-28 · **코드**: i_longonly.py · **판정: 숏 제거 = 거래당 net↑(모든 측정 일관, 숏<롱) + 숏은 음수 EV 데드웨이트(6단계 확정). 롱 전용이 거래당·구현(one-way 단순)·6단계 숏死 정합 모두 우위 → 롱 전용 권고. 단 일수익 우위는 noise 내(CI 다 0 포함). 더 큰 정직한 발견: 라이브 실제 진입방식(earliest-crossing)에선 롱도 거래당 marginal(−4.1) — 검증된 +90.5/0.084%일은 stride-10 소표본+유리한 진입phase였음. 진짜 판정 = 라이브/shadow.**

## 방법론 정합 (정직성 — 진입타이밍/stride 민감도)
숏의 "양수/음수"가 측정법에 따라 갈려서 셋 다 제시:
| 방법 | 롱 4h thr0.70 | 숏 4h thr0.70 |
|---|---|---|
| **A** stride-10 무dedup (검증 op-pt, stage4/5) | +98.7 (n62, hit .661) | **+60.9 (n17, hit .765 = 플룩)** |
| **B** dense(매분) 무dedup | +53.0 (n645, hit .575) | **−12.4 (n249, hit .506)** |
| **C** dense + causal earliest-cross (**= 라이브 실제**) | **−4.1 (n225, hit .538)** | **−14.3 (n190, hit .484)** |
- **숏 +60.9(A)는 n=17 플룩** — 표본 13배(B n249)면 −12.4. 25~28-1 6단계(코인플립/AUC0.51/kNN정렬0.00)와 일치.
- **롱도 A(+98.7)→C(−4.1)로 붕괴**: earliest-crossing(fup 첫 ≥0.70 진입=라이브 방식)이 가장 약한 진입 — stride-10 은 무작위 phase(더 강한 중간 순간)+소표본(n62)이라 낙관적. **+90.5/0.084%일 헤드라인은 진입타이밍·표본 산물**.

## 작업2 — 숏 기여 분해
- 숏 전용: hit 0.484(코인 미만), 거래당 **−14.3bp**(음수=깎음). **숏 비중 = 전체 409 중 190 = 46%**.
- 숏 일수익 기여 **−3.16bp/일**(양방향 −4.93 = 롱 −1.07 + 숏 −3.16). **숏 제거 시 full 일수익 +3.86bp/일 개선**.
- 25~28-1 일관 — 숏은 음수 EV, fee 만 내는 데드웨이트.

## 작업3 — 롱 전용 일수익 (핵심)
- **full**: 롱전용 −1.07 > 양방향 −4.93 (YES, 숏 제거가 개선). 빈도 0.476→0.262/일(45%↓)이나 음수EV 제거가 더 큼.
- **OOS test**: 롱전용 +0.26 < 양방향 +1.94 (NO) — 단 **test 숏 +6.0(n4 플룩) 때문**이고 CI 다 0 포함 = noise. 시기별 롱이 양방향 거래당 일관 우위(2024 +16.7 vs −7.7, 2025 −34.9 vs −10.8은 둘 다 음수, 2026 −22.9 vs −20.8).

## 작업4 — 라이브 반영 검토
- **숏 = 확정 데드(6단계+이번)** → 숏 게이트(롱만 진입)는 음수EV 제거라 **안전·정합**. 거래당↑, one-way 단일포지션 구현 단순화.
- 단 **일수익 우위는 noise 내**(CI 겹침) — "확실히 더 번다"는 단정 못 함. 롱 자체도 honest measure 에선 marginal.
- 권고: **롱 전용 전환**(숏 음수EV 제거 + 단순화 + 6단계 정합). 실거래 행동변경이라 사용자 확인 후 반영.

## 판정
1. **숏 빼면 거래당 net↑** (모든 측정 일관: 숏<롱). 숏 진짜 edge = 음수(B −12.4/C −14.3), A의 +60.9는 n17 플룩.
2. **롱 전용 일수익**: full 개선(+3.86bp/일), OOS 는 숏 test 플룩(n4)으로 역전되나 CI 겹침=무의미. **숏은 데드웨이트 → 빼는 게 맞음**.
3. **롱 전용 = 거래당·구현·6단계 숏死 정합 우위** → 운영점 권고. 단 "수익률 확실히↑"는 noise 라 단정 X.
4. **정직한 더 큰 발견**: 라이브 실제 방식(earliest-crossing)에선 롱도 거래당 marginal(−4.1, OOS +0.26bp/일) — +90.5/0.084%일은 stride-10 소표본+유리한 진입phase 산물. **edge 진위·크기의 최종 판정은 라이브/shadow 누적**(현 outcome 6건, 롱 gross 4/5 양수=소표본 우호적).
5. 라이브 반영(숏 게이트)은 사용자 확인 후. 산출물: STAGE30_REPORT.md, i_longonly.py.
