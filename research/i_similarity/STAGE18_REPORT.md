## 판정
1. **봉 = 새 정보 (redundancy 게이트 통과, 8단계와 다름)** — 본인 지적대로 "봉은 horizon 중복" 단정은 비약이었음. 봉은 1분봉 라벨이 안 잡는 구조를 담음.
2. **그러나 결합 두 방식 모두 ❌**: ①유사도 추가 = 방향 희석(hit 0.68→0.58, 14단계 funding 재현) ②AND/OR 모멘텀 = 역예측(0.44). **새 정보 ≠ 방향 유용.**
3. **새 교훈 (sharpening)**: 21차원 방향 edge 는 **특정 구성**에 있음 — 비중복 정보(funding, 봉)라도 kNN 에 추가하면 이웃 선택을 흐려 hit↓. 21차원은 "최소"가 아니라 **방향 task 에 튜닝된** 공간. 더 많은 정보 ≠ 더 나은 방향 kNN (차원의 저주 + target 정렬 문제).
4. **단일 4h thr0.70 (0.084%/day, 1x) 확정.** 빈도 개선 경로 (정의/청산/thr/multi-h/경로/합의/보완/구조/MTF봉) 전부 소진.
